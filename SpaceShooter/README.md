# CSharp Projects

A collection of projects developed in C# using Windows Forms.

---

## 🚀 SpaceShooter

A 2D space shooter game built from scratch in C# with Windows Forms.

### 🎮 How to play
- **Arrow keys**: move the spaceship
- **Space**: shoot (3 bullets at once)
- **P**: pause / resume the game

### ⚙️ Features
- Scrolling star background
- 10 different enemies including 2 bosses
- Enemy shooting system with increasing difficulty
- Score and level tracking
- Game Over and You Win screens
- Replay and Exit buttons
- Background music and sound effects

### 🛠️ Technologies
- C# / Windows Forms
- Windows Media Player (WMPLib)
- Visual Studio

### 📁 Project Structure
- `SpaceShooter/` - Main project folder
- `component/asserts/` - Images and icons
- `component/songs/` - Music and sound effects
